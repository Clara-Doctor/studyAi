## 线 1 · 上线冲刺线 ⭐ 我的推荐

**一句话**：用最短路径做出你第一个"被业务系统调用的 AI 服务"。

**内容拆解（约 1 周，每天 1~2 小时）**：
1. Git 闯关第 1 关：eval-practice-house 建仓+首 commit（0.5h）
2. 给 extractor.py 穿盔甲：timeout + 重试外壳，改完跑 eval 验证（1h）
3. 学 FastAPI 最小集（约 20 行的知识量）：把 extract_listing 变成 HTTP 接口（2h）
4. 本机跑通服务，用浏览器/curl 调用（1h）
5. 写一个 Java 测试类，用 resilience4j（超时/重试/降级）调你的 Python 服务（3h）
6. 全链路打通：Java 后台 → 你的 AI 服务 → Claude API → 返回结构化房源字段（0.5h 验收）

**你会了解到什么**：
- 服务化思维（函数 → HTTP 接口 → 被别人调用）
- 跨语言集成全链路（Java ↔ Python ↔ 模型 API）——架构 B 实景
- Java 侧的生产盔甲（resilience4j 三注解）
- 第一个"端到端跑在真实链路上"的东西

**完成后的你**：简历上能写"独立开发并上线了一个 AI 结构化提取服务（Java+Python 混合架构）"。
这是四条线里**唯一产生职业级产出**的。

**前提/风险**：FastAPI 是新东西（但只需 20 行知识）；需要你的 Java 环境能起一个测试工程。

## 线 2 · 工程师上手线（最全面）

**一句话**：把板块二的 11 关全部亲手做一遍，成为"能独立开发 AI 应用的入门工程师"。

**内容拆解（约 2~3 周）**：

2. 《AI应用开发详解教程》逐关做：similarity.py → rag_bot.py → rag_eval.py →
   judge.py → 重试外壳 → 缓存降级 → 调用日志
3. 毕业项目：生产级提取服务（健壮+省钱+可信+可观测+说明书）

**你会了解到什么**：

- 完整走一遍"Demo → 产品"的改造过程

**完成后的你**：板块二从"知识"变成"技能"，做任何 AI 应用需求都有了起点代码库。

**前提/风险**：战线较长，中途容易泄气（对策：每关一个 commit，进度可见）。

## 线 3 · 工作实战线（最贴身）

**一句话**：在你的真实工作项目（鸿蒙/房源）里挑一个真实需求，用完整 AI 工作流交付。

**内容拆解（1~2 周，跟工作节奏走）**：
1. 挑需求：小而完整（一个接口、一个页面模块、一个小 bug 修复链）
2. 走全套：需求三空模板 → Plan 模式出计划并修改 → worktree 隔离 →
   实现时 harmonyos-development 技能自动上场 → 自测验证 → diff 审查 → 合并

**你会了解到什么**：
- AI 结对开发的**肌肉记忆**（21 关从"学过"变"日用"）
- 领域技能真实提升（鸿蒙开发 + AI 协作同时练）

**完成后的你**：工作方式升级——这是四条线里**唯一影响你每天 8 小时**的。

**前提/风险**：需要真实工作场景和一点试错空间（别拿最紧急的需求当第一个实验品）。

## 决策指南

- 想**最快拿到一个能写进简历的东西** → 线 1

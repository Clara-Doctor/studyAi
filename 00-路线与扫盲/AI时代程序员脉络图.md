## 第 0 章 · 开始前，先立三个地基概念

### 0.1 大模型到底是什么？

剥掉所有包装，大模型（LLM）就是一个**读过几乎整个互联网的"接话机器"**：
你给它一段文字，它预测"接下来最合理的文字是什么"，一个词一个词往外蹦。

但它有三个天生属性，理解了它们，后面所有现象都能解释：

1. **它没有"知识库"，知识揉在参数里**——训练完就凝固了，训练之后世界上发生的
   事它一概不知（所以需要联网搜索/RAG 喂资料）
2. **它没有被训练过你的私有内容**——你公司的文档、你项目的代码它从没见过
   （硬问就编，这就是幻觉的根源）
3. **它只会"接话"，不会"做事"**——想让它读文件、跑命令，必须有人给它工具
   （这就是"Agent"这一整层产业存在的原因）

### 0.2 一切按 Token 计费

模型读和写都按 **token**（词元，约等于半个到一个汉字）收费。
两个推论贯穿整个产业：①上下文越长越贵（所以有 /compact、缓存、RAG 这些省钱术）；
②不同模型价差可达 10 倍（所以有"模型编排"，让贵的干少的）。
你学的《模型编排详解教程》就是这门生意的用户端玩法。

### 0.3 为什么分五层？（产业分工类比汽车业）

```
④ AI 编程工具    4S 店：你直接开的车（Claude Code、Cursor）
③ 开发框架/协议  改装厂+标准件：把发动机装进各种车的技术
② 模型服务平台   加油站：把发动机的能力按量卖给开发者
① 大模型本体     发动机厂：真正烧钱训练模型的少数玩家
（⑤ 周边专项     改装件市场：向量库、本地部署、语音图像……）
```

记住这个分工，你就掌握了"扫盲的核心技能"——**任何新名词，先归层**。
90% 的新产品，只是某一层里多了一个竞品，不值得慌。

## 第 1 章 · ①大模型层：认识所有"发动机"

### 1.1 国外闭源三巨头

| 公司 | 代表模型 | 特点一句话 |
|---|---|---|
| Anthropic | **Claude** 系列 | 编程和长任务（Agent）公认第一梯队，你在用的就是它 |
| OpenAI | GPT 系列 | 先发者、生态最大、名字成了品类代名词（"ChatGPT 一下"） |
| Google | Gemini 系列 | 背靠谷歌搜索+全家桶，多模态（看图看视频）见长 |

"闭源"什么意思？——**配方（模型权重）不给看**，你只能去它家餐厅吃饭（调它的 API）。
好处是省心、能力强；坏处是数据要出门、价格它说了算、它停服你就断粮。

### 1.2 国产阵营（便宜、追赶快、政策友好）

| 公司 | 代表 | 出名点 |
|---|---|---|
| 深度求索 | **DeepSeek**（V系列/R系列） | 极致性价比 + 开源了强模型，2025 年初震动全球——你问的 "dsh" 八成是它（常缩写 DS） |
| 智谱 | GLM 系列 | 清华系，也搞编程套餐和开源 |
| 阿里 | 通义千问 Qwen | 开源版 Qwen 是全球装机量最大的国产开源模型之一 |
| 字节 | 豆包 | C 端用户量巨大，企业走火山方舟平台 |
| 月之暗面 | Kimi | 靠"超长文本"起家出圈 |

国产的共性优势：**便宜（常有官方 API 半价以下）、中文好、数据可留在国内、
开源多**。劣势：最强闭源模型的能力上限仍略逊第一梯队（差距在快速缩小）。

### 1.3 开源 vs 闭源：配方给不给你

- **闭源** = 只能去餐厅吃（调 API）
- **开源** = 配方直接给你，**自己的厨房也能做**——下载到公司服务器上跑，
  数据一步都不出门

这条分界线直接催生了"私有化部署"这个产业（第 5 章）。

### 1.4 发动机的三种"档位形态"

同一个厂家往往同时卖三种形态，别被名字绕晕：

| 形态 | 是什么 | 适合 |
|---|---|---|
| 普通模型 | 直接回答 | 日常任务，便宜快速 |
| **推理模型**（长思考） | 回答前先写一大段内部推理，"想清楚再说" | 数学/复杂调试/规划，贵几倍但难题强 |
| 多模态模型 | 能看图/听音频/看视频 | 发票识别、截图理解 |

### 1.5 价差有多大？（给个体感）

以 Claude 官方价为例（每 100 万 token，输入/输出）：

```
Haiku（小）  $1  / $5      ← 基准
Sonnet（中） $3  / $15
Opus（大）   $5  / $25      ← 5 倍
Fable（旗舰）$10 / $50      ← 10 倍
```

同一个 Agent 循环，换挡就是换钱——《模型编排详解教程》的根基就在这张表。

## 第 2 章 · ②模型服务平台层：油从哪买

### 2.1 先懂 API 是什么

API 就是"点菜"：平台给你一份菜单（文档），你按格式发点单请求
（"用 Claude 帮我总结这段话"），它上菜（返回结果），**按量收费**。
你 extractor.py 里那行 `client.messages.create(...)` 就是在点菜。

### 2.2 三种柜台

| 柜台 | 是什么 | 谁在用 |
|---|---|---|
| **官方 API** | 模型厂直营（Anthropic/OpenAI 官网申请 key） | 要最稳、要最新功能的 |
| **云厂商平台** | 阿里百炼(DashScope)、火山方舟(字节)等——一个平台打包几十个模型 | 国内企业：要好开发票、要合规、要国产模型 |
| **聚合/中转** | OpenRouter、你正在用的**中转站**——一个 key 通吃多家 | 个人/尝鲜/省钱 |

中转站的隐性代价你亲身踩过：**功能兼容看运气**（output_format 不支持、
强制工具调用不严格）——它本质是转手生意，官方的新功能它未必跟进。
所以：生产重要业务走官方或大云，练手和省钱用中转。

## 第 3 章 · ③开发框架与协议层：变速箱和标准件

### 3.1 为什么需要框架？

裸写 API 会发现三段代码**每个项目都要重写一遍**：
①Agent 循环（调模型→执行工具→塞回结果→再调）；②工具定义与执行；
③RAG 流水线。框架就是把这三样做成现成的。
你在 agent_lib.py 手搓过循环——**你已经知道框架在替你偷什么懒**，这是多数人没有的视角。

### 3.2 常见框架点名

| 框架 | 定位 | 类比你学过的 |
|---|---|---|
| LangChain | 最大众的"瑞士军刀"，啥都有 | — |
| LangGraph | 用"状态图"编排复杂 Agent 流程 | 你第 21 关工厂的代码版 |
| LlamaIndex | RAG 专精（文档接入检索） | 你 rag_bot.py 的工业版 |
| **Claude Agent SDK** | 把整个 Claude Code 当库用 | 《AgentSDK从教学版到生产版》 |

### 3.3 协议：让"轮子"通用的标准

各家工具如果各定各的接口，生态就乱了——于是出现协议：

- **MCP**（Model Context Protocol，Anthropic 发起，已成事实标准）：
  给 AI 接工具的 **USB 标准**。工具方（数据库、GitHub、你的内部系统）按 MCP
  插一次，所有支持 MCP 的 AI 都能用它——不用每家单独适配。你装过、第 11 关练过。
- **A2A**（Agent-to-Agent，Google 发起）：Agent **互相之间**通话的标准——
  你的工厂里工人之间现在靠你传话，A2A 想让他们直接通电话（尚在早期）。
- **Skills**：给 AI 的按需操作手册（你写过 eval-methodology）。

## 第 4 章 · ④AI 编程工具层：程序员的"车"

### 4.1 三代形态演进（看懂这个，就看懂了行业方向）

```
第一代 补全（2021~）   你写一半它猜下半句          Copilot、CodeGeeX
第二代 对话（2023~）   问一句答一句，代码自己粘     ChatGPT 网页、早期通义灵码
第三代 Agent（2025~）  给任务，它自己读码/改码/跑命令 Claude Code、Cursor、Trae
```

方向箭头很明确：**人的介入越来越少，从"打字员"变成"派活的"**。

### 4.2 Agent 形态的两大派

| 派系 | 代表 | 长在哪 | 特点 |
|---|---|---|---|
| 终端派 | **Claude Code**、Codex CLI(OpenAI)、Gemini CLI(Google) | 命令行里 | 能力最完整：接管文件/命令/git，可脚本化无头运行，多实例开工厂 |
| IDE 派 | Cursor、Windsurf、Trae(字节)、CodeBuddy(腾讯)、**ZCode(智谱)** | 编辑器里 | 界面友好、上手快，深度绑定自家编辑器/模型 |

**为什么"会一辆车=会所有车"**：所有 Agent 工具的原理都是你 21 关学的那套——
模型+工具+循环+权限+上下文管理。区别只是界面和细节策略。Claude Code 你玩透了，
Cursor 上手半天，Trae 看一眼就会。

### 4.3 补全插件（第一代）还有位置吗？

有——打字快的场景它依然顺手（比如你 IDEA 里的 Copilot 类插件），
但它没有 Agent 能力（不能自己跑命令自己改十个文件），是**上一代产品**。
行业重心已整体移到第三代。

## 第 5 章 · ⑤周边专项层：改装件市场（知道存在+干什么用即可）

### 5.1 向量数据库——RAG 的仓库

你 rag_bot.py 里用 dict 存相似度——文档到几千份、要毫秒级检索时，
就该换真仓库：**chroma**（轻量入门）、**pgvector**（挂在你现有 PostgreSQL 上）、
**Milvus**（企业级分布式）。升级的只是"存和查"，五步流程原封不动。

### 5.2 本地部署/私有化——"数据不出门"的答案

- **ollama**：一行命令在自己电脑/公司服务器跑开源模型（DeepSeek、Qwen…），
  个人玩 5 分钟上手
- **vLLM**：生产级推理服务（公司真要私有化时用的）
- 谁需要：金融/政务/医院等"数据不能出门"的行业；想摆脱按 token 付费的大用量场景。
  代价：要自己买 GPU、自己管效果。

### 5.3 多模态专项：生成 vs 理解是两条线

| 线 | 干什么 | 代表 |
|---|---|---|
| 生成 | 文生图/文生视频 | Midjourney、可灵(快手)、Sora(OpenAI) |
| 理解 | 看懂图/视频/文档（多模态模型，第 1 章） | Claude、Gemini 等 |
| 语音 | 听（语音转文字）/说（文字转语音） | Whisper(OpenAI 开源) / 各家 TTS |

### 5.4 AI 搜索

Perplexity、秘塔——搜索+模型总结+**带引用来源**，查资料比传统搜索引擎快，
不写代码也用得上。

## 第 6 章 · 时间线详解：这五年发生了什么

| 年份 | 发生了什么 | 对程序员意味着什么 |
|---|---|---|
| 2022 | ChatGPT 上线，5 天破百万用户 | AI 第一次变成人人可用的聊天窗口 |
| 2023 | GPT-4、开放 API、Copilot 全员开通 | AI 变成"能力"，代码补全潮；程序员开始"调 AI" |
| 2024 | RAG 成企业标配；多模态成熟；o1 出现（第一批"会思考"的推理模型）；MCP 发布 | 知识库助手潮；"给 AI 接工具"有了统一标准 |
| 2025 | **Agent 元年**：Claude Code/Cursor 类工具成为真实生产力；DeepSeek-R1 开源震动全球（便宜+推理强）；MCP 生态爆发 | AI 从"助手"变"同事"——你学的 21 关就是这一年定型的工作流 |
| 2026（当下） | 多 Agent 协作/工厂化落地；Agent 进企业生产；A2A 等 agent 互联协议冒头 | 你站在的位置：一个人指挥一支 AI 小队 |

**一条主线贯穿始终**：模型能力每次跳一级（会聊天→会用工具→能自主多步→多 Agent
协作），人的角色就往上游移一级（打字→审查→派活→验收）。
**你全部的学习都踩在这条主线的节奏上**，没有跑偏。

## 第 7 章 · 跟进时代的操作手册

### 7.1 归层三问（配两个实战演练）

遇到新名词：①它在哪一层？②解决什么**新**问题？③对应我已经会的哪个？

> 演练 1：听说 "Trae"——归层：④编程工具，IDE 派新成员。新问题？
> 没有本质新问题，是 Cursor 的国产对标。结论：知道存在即可。
>
> 演练 2：听说 "Kimi K2 开源了"——归层：①发动机，开源档。
> 新问题？多了个能私有化的高性能选择。结论：记一笔；哪天公司要
> 数据不出门时再深入。

### 7.2 每周 15 分钟的具体动作

1. 扫一眼主力工具的更新（Claude Code 的 GitHub Releases）——**你的生产力工具
   更新了什么 > 一切科技新闻**
2. 泛资讯源挑 1~2 个，只看标题
3. 看不懂的名词记进本册小抄，归层
4. 每季度把第 6 章时间线续写一行

### 7.3 FOMO 解毒剂（背下来）

- 大多数新东西，**6 个月后再学完全不迟**——验证期过了，坑都被别人踩完了
- 真正重要的东西会以"你的主力工具更新了"的形式主动找你
- 面对吹嘘，永远问一句：**"它和 Claude Code 比解决了什么新问题？"**——
  答不上来的，一笑而过
